## Phase Goal

**As a** David (the only user), **I want to** open Shinigami Eyes and watch the red eyes activate onto a dark, tilted 3D map of my surroundings with named tags, info cards and the cameras around me, **so that** I can read my street at a glance, Watch Dogs-style, without any third party learning where I am.

This plan closes UAT gaps 3 (cosmetic: `Speed camera` label clipped at the right screen edge) and 4 (minor: an open card covers nearby tags), both seen in David's 2026-11-07 iPhone screenshot. It also finishes the guard-post wiring from 02-16 in tags.ts (spoken type), because this plan owns tags.ts in wave 2.

Design (Claude's discretion, stated):
- Label side: pure `labelSide(x, labelW, viewportW)`; flip left only when the right-hand label would cross `viewportW - EDGE` and the left-hand label fits `>= EDGE` (EDGE = 16, same margin as the card). Measured chip width (`offsetWidth`) with fallback to the CSS max (144 px). Re-evaluated in reconcile (profile update, view change, moveend debounce), not per frame.
- Card side: placeCard scores each candidate side that fits the viewport/safe band by the count of other tag rects (icons + visible labels) it would intersect; lowest wins, ties go to the previously used side, then right, left, above, below. With no other tags the result equals today's behaviour. leaderPoints already handles all four sides (no leader.ts change).
</objective>
