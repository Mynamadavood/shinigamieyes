cameras.json contract (from 02-05): `{"version":1,"built_at":float,"source":str,"cameras":[{"id","k":"cctv"|"speed"|"redlight","lat","lon", optional camera_type, direction, operator, surveillance, road, suburb}]}`.
Runtime polled tier publishes a "global" layer at (0,0) — so the camera providers must stay tier "computed" (never polled).

- `ProviderMeta.exact_location_only: bool = False`
