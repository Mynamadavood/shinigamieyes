## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → tailnet node `shinigami` | Only tailnet peers should reach :443 |
| LXC loopback → uvicorn | Only `tailscale serve` should reach :8000 |

| git repo → server config | Example files are public; real config is not |
