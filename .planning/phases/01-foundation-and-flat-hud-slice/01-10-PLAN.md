## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone → /api/geocode | Untrusted free text |
| server → Nominatim | Search text leaves the server (user-initiated) |
| Nominatim JSON → DOM | Third-party strings rendered on the phone |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-01-39 | Tampering | q parameter | mitigate | Length 3..120 after trim (422 tests); passed to httpx as a query param (encoded), never interpolated into URLs |
| T-01-40 | Tampering (XSS) | Result labels rendered in the sheet | mitigate | textContent only; label truncated to two display-name parts; grep gate on innerHTML (01-09) still applies |

| T-01-42 | Information disclosure | Search text in logs | mitigate | Logs exception class only (caplog test) |
