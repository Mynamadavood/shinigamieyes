## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package registries → dev machine | Third-party code enters the repo via `uv add` / `npm i` |
| browser → FastAPI (same origin) | Requests to `/api/*` and static files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | npm/PyPI installs (sse-starlette, astral, respx, @fontsource/*, fake-indexeddb, happy-dom) | mitigate | Task 1 blocking-human checkpoint before any install; lockfiles (`uv.lock`, `package-lock.json`) committed; installs happen once in this plan only |
| T-01-01 | Information disclosure | uvicorn access log / app logging | mitigate | Documented run command uses `--no-access-log`; logging config never logs query strings (verified again by `test_nologging` in 01-04) |
| T-01-02 | Tampering (XSS) | web/src/main.ts, index.html | mitigate | DOM built with `textContent` only; CSP `default-src 'self'; script-src 'self'; style-src 'self'; frame-ancestors 'none'` set by middleware and asserted in test_health |
| T-01-03 | Tampering | Service worker caching API responses | mitigate | sw.ts precaches shell only; NavigationRoute denylist `/^\/api\//`; `/api/*` responses `Cache-Control: no-store` |
| T-01-04 | Denial of service | /api/_sse_probe | accept | Bounded `n` ≤ 60 (422 otherwise); tailnet-only single user |
</threat_model>
