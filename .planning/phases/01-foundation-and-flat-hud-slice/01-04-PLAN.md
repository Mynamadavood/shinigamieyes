server/shinigami/schema.py (pydantic v2):
- ItemKind = Literal["place","infrastructure","transit_vehicle","aircraft","vessel","self","environment"]   # no person kinds, ever
- LayerStatus = Literal["fresh","stale","pending","error","out_of_coverage"]
- class Item(BaseModel, frozen=True): id: str; layer: str; group: str; name: str; verb: str; target_ts: float | None (ABSOLUTE epoch seconds UTC, None = value-only item); kind: ItemKind; severity: int = Field(0, ge=0, le=3); detail: dict | None = None; geom: dict | None = None (GeoJSON, Phase 2); fetched_at: float; stale_after_s: int | None (None = never stale); computed: bool = False
- class Layer(BaseModel): id: str; status: LayerStatus; rev: int; as_of: float | None; attribution: str; items: list[Item]
- class ProfileLocation(BaseModel): source: Literal["gps","pin","search","default"]; lat: float | None; lon: float | None; place_id: str | None = None; label: str | None = None
- class Profile(BaseModel): server_time: float; rev: int; location: ProfileLocation; layers: dict[str, Layer]

server/shinigami/geo.py:
- haversine_m(lat1, lon1, lat2, lon2) -> float
- @dataclass(frozen=True) Cell(id: str, lat: float, lon: float); snap_cell(lat, lon, step=0.1) -> Cell  (id like "-37.8,145.1"; lat/lon = snapped centre; upstream calls use the centre, never raw GPS)

server/shinigami/providers/base.py:
- @dataclass(frozen=True) ProviderMeta(id: str, tier: Literal["computed","polled","on_demand"], ttl_s: int, stale_after_s: int | None, attribution: str, interval_s: int | None = None)
- @dataclass ProviderContext(settings, clock: Callable[[], float], store=None, http=None, bus=None, runtime=None)   # store/http/bus/runtime filled by 01-06
- class Provider(ABC): meta: ProviderMeta; abstract def query(self, ctx, lat: float, lon: float, now: float) -> Layer  (SYNC, read-only: CPU or store reads only, never network); async def refresh(self, ctx) -> None (default no-op; polled tier); async def fetch_cell(self, ctx, cell: Cell) -> None (default no-op; on_demand tier)

server/shinigami/assemble.py:
- assemble_profile(ctx, providers: list[Provider], location: ProfileLocation, lat: float, lon: float) -> Profile   (01-06 extends it to trigger runtime.request_cell on pending/stale on_demand layers)
